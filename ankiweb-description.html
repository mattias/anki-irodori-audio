Irodori Audio creates natural-sounding Japanese sentence audio for your cards, locally on your own computer, with Irodori-TTS. It is a more human-sounding alternative to VOICEVOX, with female and male voices and emotions. Good for mining from books and manga, where you otherwise get a flat, robotic voice. It installs and starts its own local voice server, so there is nothing to set up by hand.

Features

  • Browser menu: Cards > Generate Sentence Audio (Irodori). Reads Sentence and writes SentenceAudio (field names are configurable).
  • 6 voices (3 female, 3 male) and 7 emotions: neutral, happy, sad, angry, scared, whisper, joking.
  • Male or female voice and emotion are chosen automatically by simple rules (speech style such as 俺, ぼく, だぜ, わよ, keywords, punctuation). No extra AI model needed.
  • Guided one-time setup of the voice server, which then starts and stops with Anki. When you do not use it for 10 minutes it stops by itself and frees the GPU memory, and it starts again when you need it.
  • Safe: recorded audio is never replaced, Sentence is never changed, old files are kept, one undo reverts a run, and nothing changes if the server is down.
  • Background generation with progress and cancel. Notes that get audio are tagged irodori.

Getting started

  1. Install the add-on and restart Anki.
  2. A welcome dialog offers to set up the server (also under Tools > Irodori Audio > Set up local server). It shows what will be downloaded. Click Install and start. This runs once: about 8 GB of downloads (Python packages with PyTorch, about 5 GB, and the voice model, about 3 GB), 10 GB of free disk space, a few minutes to half an hour. You can cancel and run it again later.
  3. Select 3-5 notes in the card browser and run Cards > Generate Sentence Audio (Irodori). Listen to the result before running it on many notes.

An NVIDIA GPU with about 6 GB of free VRAM is recommended (about 1 second per sentence). Without one it runs on the CPU, which works but is slow.

From then on the server starts automatically with Anki and stops after 10 minutes without use (setting IDLE_MINUTES, 0 = never), so the GPU memory is free for games and other programs. It starts again by itself the next time you generate audio. The server listens only on 127.0.0.1, so everything stays on your computer. Everything is installed into one folder (on Windows %LOCALAPPDATA%\IrodoriAudio) and Tools > Irodori Audio > Remove local server removes it again.

Troubleshooting

  • Setup fails: read the last lines of the log in the setup window and run the setup again; it continues where it stopped. If it keeps failing, open an issue and paste the log. A firewall or antivirus may block downloads from github.com, pypi.org, download.pytorch.org or huggingface.co.
  • The server does not start: use Tools > Irodori Audio > Start server. Open server log shows what went wrong.
  • First start takes minutes: the voice model is downloaded and loaded the first time.
  • Notes are skipped: notes with recorded audio are never replaced. Check that the field names in the add-on config match your note type.

Advanced (run the server yourself, Linux/macOS notes): github.com/mattias/anki-irodori-audio. Bug reports and questions: GitHub issues.

Good to know

  • Pronunciation cannot be corrected (there is no kana input). Rare names and unusual readings may be wrong, so listen first.
  • Laughs and breaths are not guaranteed. The add-on regenerates clips that run far too long (a stray cry after the sentence).
  • Whisper is the least reliable emotion.
  • The automatic setup is tested on Windows 11. Linux and macOS use the same code but are untested.
  • Do not use real people's voices as references. The model's terms forbid it. The bundled voices were created by the model's own Voice Design.
