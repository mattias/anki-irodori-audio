Irodori Audio creates natural-sounding Japanese sentence audio for your cards, locally on your own computer, with Irodori-TTS. It is a more human-sounding alternative to VOICEVOX, with female and male voices and emotions. Good for mining from books and manga, where you otherwise get a flat, robotic voice.

Features

  • Browser menu: Cards > Generate Sentence Audio (Irodori). Reads Sentence and writes SentenceAudio (field names are configurable).
  • 6 voices (3 female, 3 male) and 7 emotions: neutral, happy, sad, angry, scared, whisper, joking.
  • Male or female voice and emotion are chosen automatically by simple rules (speech style such as 俺, ぼく, だぜ, わよ, keywords, punctuation). No extra AI model needed.
  • Safe: recorded audio is never replaced, Sentence is never changed, old files are kept, one undo reverts a run, and nothing changes if the server is down.
  • Background generation with progress and cancel. Notes that get audio are tagged irodori.

Setup (Windows, about 15 minutes, 10 GB disk)

The add-on talks to a server that runs on your own computer. Everything stays local. You need an NVIDIA GPU with about 6 GB of free VRAM (CPU works but is slow).

  1. Install the tools. Open PowerShell, run the three commands below, then close PowerShell and open a new window:
    winget install --id Git.Git -e
    winget install --id astral-sh.uv -e
    winget install --id Gyan.FFmpeg -e
  2. Set up the server. In the new PowerShell window:
    cd $HOME
    git clone https://github.com/Aratako/Irodori-TTS-Server.git
    git clone https://github.com/mattias/anki-irodori-audio.git
    cd Irodori-TTS-Server
    uv sync --extra cu128 (about 5 GB, takes a few minutes; use --extra cpu without an NVIDIA GPU)
    Copy-Item ..\anki-irodori-audio\voices\*.wav voices\ (copies the six voice files the add-on needs)
  3. Start the server (in the same folder, and leave the window open):
    uv run --no-sync python -m irodori_openai_tts --host 127.0.0.1 --port 8088
    Open http://127.0.0.1:8088/health in a browser. It should say "status":"ok".
  4. Restart Anki, select 3-5 notes in the browser and run Cards > Generate Sentence Audio (Irodori). The first sentence downloads and loads the model (about 3 GB, one to several minutes). After that it takes about 1 second per sentence. Listen before running it on many notes.

Every time you restart your computer, start the server again: open PowerShell, run cd $HOME\Irodori-TTS-Server, then the command in step 3. The server only runs while its window is open.

Troubleshooting

  • "The Irodori server is not responding": the server is not running. Start it (step 3).
  • No module named irodori_openai_tts: you are in the wrong folder. Run cd $HOME\Irodori-TTS-Server first.
  • "not recognized" for git, uv or ffmpeg: close PowerShell and open a new window after installing.
  • First note takes minutes: the model is downloading and loading. Watch the server window.
  • Notes are skipped: notes with recorded audio are never replaced. Check that the field names in the add-on config match your note type.

Full instructions (Linux/macOS, AMD, more troubleshooting): github.com/mattias/anki-irodori-audio. Bug reports and questions: GitHub issues.

Good to know

  • Pronunciation cannot be corrected (there is no kana input). Rare names and unusual readings may be wrong, so listen first.
  • Laughs and breaths are not guaranteed. The add-on regenerates clips that run far too long (a stray cry after the sentence).
  • Whisper is the least reliable emotion.
  • Do not use real people's voices as references. The model's terms forbid it. The bundled voices were created by the model's own Voice Design.
