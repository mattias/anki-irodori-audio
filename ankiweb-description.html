Irodori Audio creates natural-sounding Japanese sentence audio for your cards, locally on your own computer, with Irodori-TTS. It is a more human-sounding alternative to VOICEVOX, with female and male voices and emotions.

Features

  • Browser menu: Cards > Generate Sentence Audio (Irodori). Reads Sentence and writes SentenceAudio (field names are configurable).
  • 6 voices (3 female, 3 male) and 7 emotions: neutral, happy, sad, angry, scared, whisper, joking.
  • Voice and emotion are chosen automatically by simple rules (speech style such as 俺, ぼく, だぜ, わよ, keywords, punctuation). No extra AI model needed.
  • Safe: recorded audio is never replaced, Sentence is never changed, old files are kept, one undo reverts a run, and nothing changes if the server is down.
  • Background generation with progress and cancel. Notes that get audio are tagged irodori.

You run the Irodori server yourself

The add-on only talks to a server on your own computer. Everything stays local.

  1. Requirements: NVIDIA GPU with about 6 GB free VRAM (CPU works but is slow), git, uv and ffmpeg.
  2. git clone https://github.com/Aratako/Irodori-TTS-Server.git. In that folder run uv sync --extra cu128 (use --extra cpu without a GPU) and copy .env.example to .env.
  3. In .env set IRODORI_HOST=127.0.0.1 and IRODORI_HF_CHECKPOINT=Aratako/Irodori-TTS-v4-Small.
  4. Download the six reference voice files (voices/*.wav) from the GitHub page and put them in the server's voices folder.
  5. Start: uv run --no-sync python -m irodori_openai_tts --host 127.0.0.1 --port 8088. The first start downloads the model.
  6. Restart Anki, select a few notes in the browser and run the menu item. Listen before running it on many notes.

Full instructions: github.com/mattias/anki-irodori-audio. The six voice files are in the voices folder (download each .wav, or download the whole repository as a zip). Bug reports and questions: GitHub issues.

Good to know

  • Pronunciation cannot be corrected (there is no kana input). Rare names and unusual readings may be wrong, so listen first.
  • Laughs and breaths are not guaranteed. The add-on regenerates clips that run far too long (a stray cry after the sentence).
  • Whisper is the least reliable emotion.
  • About 0.9 s per sentence on an RTX 4080.
  • Do not use real people's voices as references. The model's terms forbid it. The bundled voices were created by the model's own Voice Design.
